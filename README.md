# open-knot-agent

**An agent core for embedded systems. Source publishing 2026-12-01.**

The model does the thinking. The board does the living. A cloud model supplies the
intelligence, a non-blocking state machine is the loop, and internal flash is the
memory. One reference board — the DFRobot UNIHIKER K10, ESP32-S3 — proves the whole
path on real hardware.

This repository is a placeholder until the launch. On **2026-12-01** it fills with the
core, the design documents, the host test suite and the board.
